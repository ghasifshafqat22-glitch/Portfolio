# Game UI Portfolio

## Put it online (free, GitHub Pages)
1. Make a free account at github.com.
2. Create a new **public** repository (e.g. `portfolio`).
3. Upload everything in this folder to the repository (drag and drop on the repo page, then "Commit changes").
4. Repository **Settings > Pages**: Source = "Deploy from a branch", Branch = `main`, folder `/ (root)`, Save.
5. After about a minute your site is live at `https://<your-username>.github.io/portfolio/`

## Add a game
1. Open the `games` folder in your repository.
2. Click **Add file > Upload files** and drag in a whole folder named after the game (e.g. `Bus Simulator`) with its screenshots.
3. Commit. The site shows it automatically within a few minutes.

- Screens show in filename order: name them `01.png`, `02.png`, ...
- Optional: add `cover.png` (or .jpg) in a game folder to choose its thumbnail. Otherwise the first screen is used.
- JPG/WebP files load faster than large PNGs.

## Edit your details
Edit `config.js` on GitHub (pencil icon): name, role, intro, skills, email, links.
